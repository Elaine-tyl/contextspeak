# Vocabulary expansion

For English word selections using the configured Gemini text provider, the extension first renders the saved/transient translation, then asks separately for up to two common near-synonyms and two spelling lookalikes. Each suggestion includes a target-language usage contrast and an original bilingual example. The base translator is never called again. Phrases, non-English selections, older cards and unavailable expansion services keep the original translation.

Expansion is optional and failure-tolerant: quotas, invalid model output, older extension backgrounds, panel closure or a newer selection cannot replace a successful base result. Language controls become usable after the base result; a per-request revision prevents late expansion from overwriting a newer lookup. An account change clears the old result. Model content is rendered as text, never HTML.

`POST /v1/expansions` accepts a bounded English selection, saved meaning and optional owned lookup ID. For captured queries, the server verifies ownership/content and uses its saved meaning, not a caller-supplied replacement. Successful expansion updates only the same lookup's learning-details JSON, preserving the translation. Collection-off queries have no history/review writes. Suggestions never auto-enrol in FSRS. The library uses the same saved expansion as the popup.

Results are coalesced and cached per account, context, language pair and meaning for up to 24 hours (500 entries). The service limits two concurrent generation requests and five new requests per user/minute. Gemini uses the existing server-only key and quota; no new cloud fallback is enabled for local text providers. The prompt treats selection/context as data, requires useful alternatives rather than invented words, and does not claim sourced frequency ranks or pronunciation diagnosis. Shape validation, duplicate/identity checks, English spelling distance and whole-word example checks filter unsafe or irrelevant output. Semantic usefulness remains an AI estimate.

Old learning-card records remain valid. Expansion provenance records its model; original translation provenance is unchanged. Restart the API and reload the rebuilt extension to use the new optional message. Source code tests cover base-before-enrichment ordering, preserved failures, stale backgrounds, account/panel changes, context caching/ownership, canonical persistence and transient-query privacy.
