# Natural AI speech and example speakers

Selected approach: Gemini free-tier speech with server-side audio caching; billing unchanged. The public probe returned valid WAV audio from `gemini-3.8-flash-lite-tts`, which the official Developer API pricing lists with a free tier. Use that fixed model and Kore voice; no paid-model fallback.

Design: authenticated POST /v1/speech accepts at most 600 characters and one of the six supported source languages. Only clicked text and a language/style instruction go to Google. Validate bounded WAV output, cache successes privately by user/text/language for 24 hours with a 32 MB/100-entry process limit, coalesce duplicate requests, and bound new requests/concurrency. Cached audio remains available on provider quota errors; errors are not cached.

Web speaker buttons use a shared cancellable AI audio player and existing login. Extension speakers request audio through the authenticated worker and play in an offscreen extension document so webpage media CSP cannot block it. Stop pending/playing speech when cards close, examples change, pages leave or accounts disconnect. No visible playing text and no automatic audio. Add speaker icons to original-language phrases and example sentences in both learning-note renderers. Keep recorded user audio local and leave existing on-device practice/FSRS behavior unchanged.
