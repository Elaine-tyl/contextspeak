# Campus café design and test-stage selection

User direction approved in chat: cute campus style + cream and light-wood café.
Players/friend should read as roughly fifteen-year-old cartoon teenagers, dressed
in attractive everyday campus clothing (relaxed tops/jackets, trousers/skirts and
sneakers). Avoid merely shrinking a realistic adult. Retain free licensed art,
existing voiced ordering and seated dialogue, local AI and readable code.

Art approach: inspect the free Quaternius Teen base and compatible free animation
library first; use a compact subset with explicit provenance. Dress the avatars
in original non-revealing campus outfits, keeping silhouettes and colors distinct.
If that rig cannot support the required free seated/walk clips, adapt the existing
rig's silhouette/clothes instead of shipping broken motion. This fallback must be
reported honestly. Age is an intended art direction, not a verified age attribute.

Café: cream walls, pale wood, sage green seating/counter accents, pendant lighting,
slatted timber detail, greenery, framed café graphics and a deliberate friend-table
focal point. Preserve walkable routes, visibility and the dialogue reading area.

Test stages: an explicit header selector + Select button offers the real saved
journey and isolated previews of ordering, preferences, weekend plans, invitations
and completion. Preview progress cannot overwrite normal browser/native saves;
show Test preview clearly, cancel audio/record/model work before switching, and
make Restart return to the selected preview. These are checkpoints in the existing
mission, not a claim that ten new difficulty levels exist.

Approaches considered: edit current adult-looking rig (less download/retargeting,
limited silhouette); use an actual free Teen rig and compatible animations (better
age direction, more integration work); create a full new custom character pipeline
(out of scope). Prefer the free Teen rig if its free contents support the journey.
